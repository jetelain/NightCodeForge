# NightCodeForge.Infrastructure.Migrations

> **Assembly:** `NightCodeForge.Infrastructure` | **Layer:** Infrastructure / Database Migrations  
> **Role:** Stores Entity Framework Core schema migrations history, designer files, and current model snapshots.

---

## 1. Core Responsibility

`NightCodeForge.Infrastructure.Migrations` tracks schema evolution for the SQLite application database. Migrations are compiled via the `dotnet ef migrations` CLI tool against `AppDbContext` and applied automatically at application launch via `Database.MigrateAsync()`.

## 2. Key Types & Contracts

| Type | Kind | Description |
| :--- | :--- | :--- |
| `InitialCreate` | Class | Initial baseline migration creating tables for workspaces, tasks, workflows, stages, checkpoints, and questions. |
| `AppDbContextModelSnapshot` | Class | Snapshot of the current EF Core relational mapping schema used to calculate diffs for future migrations. |

## 3. Dependencies & Interaction Graph

- **Inbound (Who uses this):** `AppDbContext.Database.MigrateAsync()`, `dotnet ef` CLI tools.
- **Outbound (What this relies on):** `Microsoft.EntityFrameworkCore.Migrations`, `NightCodeForge.Infrastructure.Data.AppDbContext`.

## 4. Invariants & Architectural Rules

- **Rule 1 (Automated Application):** Migrations must be safely applied on application startup through `EnsureDatabaseCreatedAndWalAsync`.
- **Rule 2 (No Manual Edits to Generated Code):** Migration C# files and snapshots are generated by EF Core CLI; manual structural modifications are strictly discouraged without updating the snapshot.
- **Rule 3 (CLI Command Standardization):** Adding new migrations must use standard dotnet ef commands referencing the startup project `NightCodeForge.Web`.

## 5. Usage Example

```powershell
# Adding a new migration from repository root
dotnet ef migrations add AddNewFeatureField `
  --project src/NightCodeForge.Infrastructure `
  --startup-project src/NightCodeForge.Web

# Updating the database directly via CLI
dotnet ef database update `
  --project src/NightCodeForge.Infrastructure `
  --startup-project src/NightCodeForge.Web
```
